# 多功能协议与信号调试器（FPGA 实现）

> 2025 年高云 FPGA 竞赛全国三等奖 | 平台：ACG720-138K | 开发环境：Gowin IDE 1.9.11

基于高云 Gowin FPGA 的多功能数字/模拟信号分析与调试系统，集成串行协议转换、数字信号测量、模拟信号采集与波形生成等功能。

**注意：** 本仓库仅包含硬件 Verilog 代码，不含上位机软件。如需软件代码，请联系：3135431783@qq.com。

---

## 功能列表

### 串行协议转换
- USB CDC 转 UART / SPI / I2C / PWM，支持主机下发命令驱动外设
- 多路用户自定义循环序列输出

### 数字信号测量
- 8 通道数字信号采集与协议解析（UART、I2C、SPI）
- 频率、占空比、高低电平时间测量

### 模拟信号采集
- 双通道模拟信号采集与波形显示
- 驱动外部高速 ADC（并口 / LVDS），采样率 ≥ 10 Msps
- 实时采样、DDR3/FIFO 缓存、USB/以太网传输

### 模拟信号输出（波形发生器）
- 双通道输出，驱动外部高速 DAC（并口 / LVDS），采样率 ≥ 10 Msps
- 支持正弦波、方波、三角波、锯齿波及用户自定义手绘波形
- 幅度、相位、幅值可调

### 存储与传输
- DDR3 控制器 + FIFO 大容量采样缓冲
- 缓冲模式（先存后传）与流模式（边采边发）

## 构建与烧录

1. 在 Gowin IDE 中打开 `ALL.gprj`
2. 配置目标器件为 ACG720-138K，检查约束文件（.cst / .sdc）
3. 运行 **综合 (Synthesis)** → **布局布线 (Place & Route)** → **生成比特流**
4. 通过 JTAG 将生成的 `.bin/.fs` 烧录到 FPGA

使用 USB CDC 通信时，主机端需安装虚拟串口驱动，使用串口工具或上位机软件进行交互。

## 验证测试

- **协议桥测试**：通过 CDC 虚拟串口发送 SPI/I2C/UART 命令，用逻辑分析仪确认时序
- **模拟采集验证**：输入已知信号到 ADC，验证采样数据正确传输到主机
- **波形发生器验证**：DAC 输出各波形，用示波器验证频率、幅度
- **数字测量验证**：输入已知频率/占空比方波，对比 FPGA 测量值与示波器读数

## 已知约束

- 外部 ADC/DAC 需与 FPGA 板卡引脚和时序兼容，本仓库提供接口逻辑，需根据具体器件调整时序
- 实际采样性能取决于硬件选型与时钟配置
- 推荐使用带外部 DDR3 的开发板以支持大容量缓存
