# 多功能协议与信号调试器（FPGA 实现）

## 项目概述

本工程基于高云（Gowin）FPGA 平台，旨在实现一个多功能数字/模拟信号分析与调试器。系统集合了串行协议转换、数字信号测量、模拟信号采集与生成等功能，支持把 FPGA 与外部高速 ADC/DAC、存储器和主机通信接口（USB/以太网等）结合，用于信号采集、存储、回放与协议调试。

本仓库为该系统的 Verilog 源码及工程文件，目录结构见 `src/`、`impl/` 等（工程已经包含 Gowin 综合与布局布线产生的文件）。


## 主要实现功能

- 串行协议转换（基线实现）
  - 基于 CDC（USB 虚拟串口）驱动的 USB 到 SPI / I2C / UART 等协议桥接，支持通过主机下发命令驱动从机外设或读取外设数据。
  - 多路 PWM 输出控制接口。

- 数字信号测量
  - 周期性数字信号的频率测量。
  - 占空比（Duty Cycle）测量。
  - 高电平/低电平时间测量（上/下降沿间隔计时）。

- 模拟信号采集
  - 驱动外部高速 ADC（并口或 LVDS 接口），支持采样率不低于 10 Msps 的采集配置（取决于 ADC 硬件性能与接口设计）。
  - 实时采样、缓存（DDR/本地 FIFO）与向主机传输（USB/以太网）。

- 模拟信号输出（发生器）
  - 驱动外部高速 DAC（并口或 LVDS 接口），支持采样率不低于 10 Msps。
  - 支持多种波形：正弦波、方波、三角波、锯齿波，及自定义波形输出（任意波形表/点阵）。

- 存储与传输
  - 使用 DDR3（或片上/外部 FIFO）实现采样数据的高速缓存与转发。
  - 支持缓冲模式与流模式：可先缓存再传输，或边采样边流式发送到主机。


## 技术参数（依据设计目标与截图要求）

- 推荐 FPGA 平台：ACG720。
- ADC / DAC 接口：并行，采样率 >= 10 Msps。
- 波形类型：正弦 / 方波 / 三角 / 锯齿 / 手绘自定义。
- 数字测量分辨率：基于 FPGA 时钟及计数器，典型可到纳秒级（依时钟频率）；测频范围由输入信号及时钟决定。
- 通信链路：USB（CDC / USB HS 可优化为高速），可扩展以太网以提升传输速率。
- 存储：使用 DDR3 控制器与 FIFO 做大容量采样缓冲（源代码中包含 `ddr3_ctrl_2port` 等模块）。


## 仓库中关键模块说明（摘要）

下面列出仓库 `src/` 下的一些关键模块与其职责：

- `src/ADC/`：与 ADC 相关的顶层与接口代码，包括 ADC 配置、采样和数据打包逻辑（例如 `ad_8bit_to_16bit.v`、`top_acm2108_ddr3_rgmii.v` 等）。
- `src/USBHS/`：USB 相关模块，包括 FX2 / CDC / USB FIFO 接口与串口通信实现（例如 `FX2_CDC_UART_SPI.v`、`fx2_fifo_crtl.v`）。
- `src/fifo_rx/`、`src/fifo_tx/`、`src/rd_data_fifo/`、`src/wr_data_fifo/`：各类 FIFO 实现与读写适配，用于数据缓存与流控制。
- `src/ddr3_ctrl_2port/`：DDR3 双端口控制器（`ddr3_ctrl_2port.v`、`fifo_ddr3_adapter.v`），用于大容量采样数据的存取。
- `src/eth_udp_gmii/`：以太网 UDP/GMII 接口（`eth_udp_rx_gmii.v`、`eth_udp_tx_gmii.v`），可用于高吞吐量传输（若启用以太网功能）。
- `src/gowin_pll/`、`src/eth_pll/`：时钟与 PLL 生成模块。
- `src/rd_data_fifo/`、`src/wr_data_fifo/`：读写数据通道的 FIFO，实现 DDR 与外设/主机之间的数据缓冲。
- 顶层文件：`src/TOP_ALL.v`、`src/ALL.cst`、`src/ALL.rao` 等以及 `impl/` 中的 Gowin 工程文件用于综合、布局布线与生成烧录文件。


## 构建与烧录（建议步骤）

注意：实际的工具链与步骤取决于所使用的 Gowin 版本与 FPGA 型号，以下为常见流程：

1. 在 Gowin IDE 中打开工程文件（例如仓库根目录下的 `ALL.gprj` 或 `impl/gwsynthesis/acm1030_ddr3_rgmii.prj` / `impl/project_process_config.json` 等）。
2. 配置目标器件（ACG525 / ACG720），设置约束与时钟（sdc 文件在 `src/ADC/` 等目录中可能包含样例 sdc）。
3. 运行综合（Synthesis） -> 布局布线（Place & Route） -> 生成比特流/二进制（.bin/.fs 等）。
4. 使用官方下载工具或 JTAG 将生成的 bitstream 烧录到 FPGA（参考开发板手册）。

如果需要通过 USB 或 FX2 芯片与主机通信，请在主机端安装相应驱动与控制软件（例如通过虚拟串口访问 CDC），并使用串口工具或开发的 GUI 进行交互。


## 功能验证与测试建议

- USB/协议桥测试：通过主机打开 CDC 虚拟串口，发送 SPI/I2C/UART 命令并观察外设响应；在 FPGA 端使用逻辑分析或示波器确认信号时序。
- 模拟采集验证：将已知频率/幅值的信号输入 ADC，验证采样数据在 FPGA/DDR/FIFO 中缓存并能正确传输到主机。
- 波形发生器验证：配置 DAC 输出正弦/方波/三角波，使用示波器验证波形频率与幅度、失真情况。
- 数字测量验证：输入已知频率与占空比的方波，比较 FPGA 测量结果与示波器读数。
- 传输模式验证：在流模式下持续采样并传输，评估丢包/丢样情况；在缓冲模式下采集后再传输，验证数据完整性。


## 已知约束与假设

- 外部 ADC/DAC 器件与其接口（并行 / LVDS）需与 FPGA 板卡引脚与时序兼容，本仓库提供 FPGA 端接口逻辑但不包含具体 ADC/DAC 器件驱动库（需根据所选器件调整时序与 PHY）。
- 采样率与测量精度受 FPGA 时钟频率与外设带宽限制；项目目标为 >= 10 Msps，但实际性能依赖硬件选型。
- 推荐使用带有外部 DDR3 的开发板以便大容量数据缓存与回放（源码中包含 `ddr3_ctrl_2port` 相关模块）。


## 可选扩展（优先级供参考）

- 通信接口优化：将 USB 优化为 USB HS 或增加以太网高速通道以提升主机数据吞吐量。
- 多通道同时采集与自定义序列输出（多路同步采样/输出）。
- 设计用户侧分析软件或 GUI：显示时域波形、频谱、提供触发/测量界面与协议解析功能。
- 增加 CAN、SPI 的更多从/主模式支持以及触发采样功能。
- 性能改进：DMA 路径、以太网 offload、并行 FIFO 优化以减少数据丢失。
